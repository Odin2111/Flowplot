# Validation data dialog

See the project store doc `fieldplot-validation-data.md` for the full walkthrough.

**Agents → Validation data…** downloads ERCOFTAC (`plotagent`), NASA (`nasaagent`), and arXiv case data into `~/.fieldplot/validation_cache/` (deletable). Agents stay read-only until **Plot compare** (experiment = symbols, simulation = lines).
